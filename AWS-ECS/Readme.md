
# 🚀 AWS ECS – Elastic Container Service

A simple project demonstrating deployment of containerized applications using **AWS ECS**.

## 🌐 What is ECS?

AWS ECS is a fully managed container orchestration service that helps you **run, scale, and manage Docker containers** on AWS without managing servers.

## 🔧 Key Features

* 🐳 Run Docker containers effortlessly
* 📈 Auto scaling & high availability
* 🔐 Integrated with IAM & AWS services
* ⚡ Supports EC2 & Fargate launch types

## 🛠️ Services Used

* AWS ECS
* Amazon ECR
* EC2 / Fargate
* Application Load Balancer

## 📌 Use Case

Deploying and managing containerized web applications in a scalable and production-ready environment.
