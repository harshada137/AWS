
# Amazon CloudFront

## 📌 Overview

Amazon CloudFront is a **fully managed content delivery network (CDN)** that delivers data, videos, applications, and APIs globally with **low latency** and **high transfer speeds**. It integrates with other AWS services like S3, EC2, API Gateway, and Lambda@Edge.
